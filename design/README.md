# design

The Claude Design canvas this site was built from: "Warren's Quartz Home".
Source artifact: https://claude.ai/code/artifact/f5acf5a0-bd37-4a41-9124-b19780f73784

Files are the raw artboards extracted from the artifact (each `.dc.html` is one standalone
artboard; `canvas.json` is the canvas layout). They are reference only; nothing in the build reads them.

- `Main.dc.html` — home page (the layout the site follows; see `../../home.png`)
- `Note.dc.html` — a note page (see `../../note.png`)
- `Tools.dc.html` — the tools shelf (see `../../tools.png`)
- `Terminal.dc.html` — alternate home concept, terminal style (not built)
- `Pipeline.dc.html` — alternate home concept, pipeline diagram (not built)
- `canvas.json` — artboard positions and sizes

Saved 2026-08-24.
